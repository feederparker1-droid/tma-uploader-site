Privacy Policy

TMA-Uploader · last updated 2026-09-22

What this application is

TMA-Uploader is a private, single-user desktop utility operated by its owner to upload and manage videos on the owner's own YouTube channels. It is not offered to the public.

Google user data

The application requests YouTube Data API access (upload, manage videos and captions) solely for the owner's own channels. Access tokens are stored locally on the owner's computer and are never transmitted to any third party.

Data collection

The application does not collect, store, sell or share personal data of any person. It does not use cookies, analytics or advertising.

Limited Use

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from the Google Account permissions page (myaccount.google.com/permissions).

Contact

Questions can be sent to the support e-mail address shown on the Google sign-in consent screen of this application.
